How it works

Four steps.
One complete launch.

Every tool you need to go from idea to live token with liquidity — in a single app.

01 —
Create your token

Name, symbol, description, logo — uploaded to IPFS via Pinata for permanent decentralized storage. The token is minted on-chain as an SPL token with Metaplex on-chain metadata. Choose supply, decimals, and dev allocation. Optionally revoke mint and freeze authorities after vesting for a fully trustless token.

SPL Token Metaplex IPFS / Pinata
02 —
Set up vesting

Lock your dev allocation using Streamflow, a fully audited vesting protocol on Solana. Configure a cliff period and total duration. Tokens unlock linearly and transparently on-chain — no trust required. Set up vesting before revoking authorities to keep everything compatible.

Streamflow On-chain vesting Audited protocol
03 —
Add liquidity

Create a concentrated liquidity pool on Orca Whirlpool — Solana's leading AMM. Choose your pair (token / SOL or token / USDC), set an initial price, and deposit. Pool init, tick arrays, SOL wrapping, and position opening are all handled automatically. Your position is a Whirlpool NFT you fully own.

Orca Whirlpool Full-range position WSOL auto-wrap
04 —
Share your public page

Every token gets a shareable public page at /token/[mint]. Live price from DEXscreener, embedded chart, top holders, supply, vesting status, and social links — all pulled from on-chain metadata automatically.

DEXscreener Live price Vesting status
